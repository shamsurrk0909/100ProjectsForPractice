# Button Ripple Effect

![Button Ripple Effect Demo](screenshot.png)

An interactive, modern button featuring a smooth ripple animation that originates exactly from your cursor position on hover. Built with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- **Cursor Tracking**: Uses JavaScript to calculate the precise mouse position and updates CSS variables dynamically.
- **Fluid Animations**: Implements CSS `::before` pseudo-elements, `overflow: hidden`, and transitions for a seamless, expanding ripple effect.
- **No Dependencies**: Built entirely with plain HTML5, CSS3, and DOM manipulation.

## 🚀 How to Run
Simply clone or download the repository, then open `index.html` in any web browser to interact with the button.
