# 🧮 Shamsur's Calculator

A modern, personalized calculator built with HTML, CSS, and JavaScript. Features a sleek dark theme with gradient effects and keyboard support.

![Status](https://img.shields.io/badge/Status-Completed-brightgreen)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![CSS](https://img.shields.io/badge/CSS3-Styled-blue)

---

## ✨ Features

- ➕ Basic arithmetic operations (+, -, ×, ÷)
- ⌨️ Keyboard support
- 🎨 Modern dark theme with gradient effects
- 📱 Fully responsive design
- ❌ Error handling
- 🔄 AC (Clear All) and DEL (Delete) functions

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling with animations
- **JavaScript (ES6+)** – Logic and interactivity

---

## 📦 Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/shamsur-calculator.git
```

2. **Open `index.html`** in your browser

---

## 🎯 How to Use

1. Click buttons or use your keyboard
2. Press `=` or `Enter` to calculate
3. Use `AC` to clear or `DEL` to delete last digit
4. Press `Esc` to reset
